# Arquivos necessários / Required files

Nenhum arquivo do jogo faz parte deste repositório. Use o dump do **seu** PS4: Fist of the North Star: Lost Paradise
(CUSA12781, v1.09). / No game file is in this repository. Use a dump from **your own** PS4.

Pasta do jogo / game folder:
- `eboot.bin` (ou o `eboot.elf` decriptado; o launcher cria a cópia `eboot.bin` numa pasta de trabalho)
- `sce_sys/` (`param.sfo`, `icon0.png`, ...)
- `sce_module/libc.prx`, `sce_module/libSceFios2.prx`
- `data/` e o restante do dump

Do firmware do console: nada. / From the console firmware: nothing.
Detalhes técnicos e estado: `port/docs/lost-paradise/README.md`.
